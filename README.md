# 📖 Deskripsi Proyek

Proyek ini merupakan platform digital storytelling yang dirancang untuk mendukung penulis dan pembaca dalam berbagi serta menikmati cerita secara interaktif. 
Fokus utama kami adalah menghadirkan pengalaman menulis dan membaca yang personalized, dengan antarmuka yang sederhana namun modern, sehingga dapat diakses oleh berbagai kalangan.
